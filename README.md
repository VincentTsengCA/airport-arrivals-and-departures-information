# 🛬 Airport Arrivals And Departures Information 🛫

**Made By Vincent Tseng ([@VincentTsengCA](https://github.com/VincentTsengCA))**


## ✈️ Overview ✈️

Use this [web application](https://vincenttsengca.github.io/airport-arrivals-and-departures-information/) to view the arrivals and departures of an airport! I used HTML, CSS, JavaScript, REST APIs, and GitHub Pages to create this website.

![Screenshot 01 - Overview](/images/Screenshot01.png)


## 🌐 How To Use 🌐

To search for an airport's arrivals and departures, enter that airport's 4-letter ICAO indentifier code into the search bar and press `Enter` on your keyboard.

If you don't know your airport's ICAO code, you can find it here: [Wikipedia - List of airports by ICAO code](https://en.wikipedia.org/wiki/List_of_airports_by_ICAO_code:_A).

Also, you can click `Random Search!` if you want the website to search a random airport for you.

![Screenshot 02 - How To Use](/images/Screenshot02.png)

If your search is valid, you will be able to see the arrivals and departures of that airport.

Each result will display the flight's type, departure/arrival airports, call sign, ICAO24 code, and first/last seen timestamps.

Additionally, you can filter all of the search results by flight type and day.

![Screenshot 03 - How To Use](/images/Screenshot03.png)
